cheap to redo, the simplest reading that satisfies the text was taken and recorded here. Anything
expensive (storage schema, wire behavior, public config keys) is also listed in the gate report's
Questions so it is confirmed before code depends on it. Format: id, date, decision, why, where it
is applied, cost to reverse.
